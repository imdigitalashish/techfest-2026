# Public indoor datasets for Namma Space — research pass

> Scope: prove the phone-capture → Gaussian-splat → WASD web twin → POI/search → obstacle-aware path → AR pipeline, and benchmark its components, using public datasets instead of (or alongside) our own capture.
> Rules followed: primary sources only, every URL opened before citing, access date **2026-10-04** recorded on every claim, `UNVERIFIED` used wherever a primary source could not be opened in this pass. No large files were downloaded — only `curl -sI` HEAD checks and direct small-file (README/LICENSE/script) reads.
> Two research agents (`research`-type, 2 attempts each) failed with infrastructure timeouts (`408 Timed out reading request body`) before any tool call — flagged per dataset below as **AGENT-FAILED, hand-verified instead**. One `general-purpose` retry succeeded (Replica/Matterport3D/HM3D/Structured3D/Hypersim) and its findings are folded in with full citations intact.

## TL;DR

- **Our existing pick (Deep Blending `drjohnson` via `nvs-bench/deepblending`) is provenance-clean but mislabelled.** The images are the real Hedman et al. 2018 photos (filenames `IMG_6292.jpg`…, identical set to Inria's own redistribution). The HF dataset card self-tags `license: mit` with **zero discussion** in its README beyond that YAML line — this conflicts with the original rights-holders' (UCL + Inria) license, which is explicitly **"non-commercially, i.e., for research and/or evaluation purposes only"** [LICENSE.md](https://gitlab.inria.fr/sibr/projects/inside_out_deep_blending/-/raw/master/LICENSE.md) — accessed 2026-10-04. A mirror cannot unilaterally relicense someone else's copyrighted photographs. **Treat it as non-commercial/research-only, not MIT.** For a Techfest academic demo this is fine (the license explicitly permits public display/distribution of derivative works for research/evaluation, with attribution); it is **not** cleared for Juspay to commercialise later without contacting Inria.
- **Same mislabelling pattern recurs**: `GaussianWorld/scene_splat_7k` (SceneSplat-7K, ICCV 2025) self-tags `cc-by-sa-4.0` on Hugging Face while repackaging ScanNet/Matterport3D/HM3D-derived 3DGS — each of those sources is individually non-commercial/no-redistribution. Don't trust a mirror's license tag over the original data agreement.
- **Tanks and Temples' own license page contradicts itself**: the "Copyright" section claims CC BY 4.0 (commercial OK), but the very next "License Grant" paragraph restricts use to "non-commercial scientific research" and forbids redistribution without written permission [tanksandtemples.org/license/](https://www.tanksandtemples.org/license/) — accessed 2026-10-04. Follow the stricter clause until the authors clarify.
- **No-registration, direct-download, real-photo datasets exist today**: Deep Blending, Mip-NeRF 360, Tanks & Temples (training-set scenes, incl. Church + Meeting room with ground-truth laser scans), Eyeful Tower (genuinely MIT), ARKitScenes, Replica, Hypersim, MuSHRoom (Zenodo). These cover **render quality** well; almost none carry semantics, floor plans, or POI labels.
- **Semantics/floor-plan/navigation-ready data is gated behind signed agreements** (ScanNet/ScanNet200, ScanNet++, Matterport3D, HM3D) or synthetic (Structured3D, Hypersim, the brand-new **InteriorGS**). InteriorGS (2025) is the standout new find: ships **pre-trained 3DGS + 3D object boxes (554k instances/755 categories) + occupancy grids + machine-readable floor plans**, gated only by an automatic HF click-through — extremely well matched to Round 2 (POI/search/pathfinding) prototyping, but it's synthetic, not phone-captured.
- **ARKitScenes is the most strategically interesting pick**: real iPad/iPhone LiDAR capture (closest device analogue to our own SOP), direct `download_data.py` script (no registration), 3D object boxes + poses, **and** Apple's license explicitly grants broader (commercially-usable) rights to any org under 700M MAU [LICENSE](https://raw.githubusercontent.com/apple/ARKitScenes/main/LICENSE) — accessed 2026-10-04 — which plausibly includes a student team / Juspay.

## Recommendations

### (a) Best no-registration dataset for tonight

**Keep `drjohnson` running** (already in progress — provenance is clean, just don't rely on the HF "MIT" tag; treat as non-commercial/research, which a Techfest demo satisfies). **In parallel, pull Mip-NeRF 360 `room` or `kitchen`** from [jonbarron.info/mipnerf360/](https://jonbarron.info/mipnerf360/) — accessed 2026-10-04: same zero-friction direct download, and it is *the* reference scene nearly every Gaussian-Splatting/nerfstudio tutorial validates against, so COLMAP → gsplat → SuperSplat/Spark compatibility risk is minimal. Both are single-room, DSLR-quality, and will give a good-looking WASD walkthrough fastest.

**Then, same evening if time allows, grab one ARKitScenes `video_id`** via `download_data.py` (direct, no registration, pick one small `raw` capture with `--download_laser_scanner_point_cloud`) — it is the only dataset in this list that is simultaneously (i) real indoor phone/tablet-sensor capture, (ii) zero-registration, and (iii) carries ground-truth poses **and** 3D object boxes, so it can validate the pose-accuracy and geometry components the pure-NVS sets (Deep Blending, Mip360) cannot.

### (b) Best dataset per component metric

| Component | Recommended dataset | Why |
|---|---|---|
| **Pose accuracy** | ARKitScenes (quick) / ScanNet++ v2 (thorough) | ARKitScenes ships ARKit pose + laser-scan depth GT with zero gating. ScanNet++ v2 added an explicit **iPhone-vs-DSLR NVS benchmark** (Oct 2025) — directly mirrors "phone capture judged against a higher-fidelity reference," our exact use case — but is gated. |
| **Render quality (PSNR/SSIM/LPIPS)** | Mip-NeRF 360 + Deep Blending + Eyeful Tower | These three *are* the field's standard render-quality leaderboard scenes. Eyeful Tower is the only one with a clean MIT licence, so it's the safest to show in a public demo video. |
| **Floor/obstacle geometry (navmesh)** | InteriorGS (ready-made) / Structured3D (from-scratch GT) | InteriorGS ships a top-down occupancy grid (`occupancy.png`, free/occupied/unknown) and a room-polygon `structure.json` — you can wire a pathfinder to it with almost no preprocessing. Structured3D is the better choice if you want ground truth to validate *your own* floor/plane-extraction algorithm against (it gives raw planes/junctions, not a pre-baked grid). |
| **POI detection** | InteriorGS (755 categories + 3D boxes) / ScanNet200 (200-class, real scans) | InteriorGS wins on category richness and ships instance boxes directly; ScanNet200 wins if you need real (non-synthetic) RGB-D to test detection robustness. |
| **Search** | Same two as POI | Spatial search only needs labelled regions/objects to index — both qualify; InteriorGS additionally gives room-level `room_type` strings ("Living and Dining Room") which map directly to a text-search UI. |
| **Relocalisation** | 7-Scenes (fast/classic) / 12-Scenes (best licence) | These *are* the canonical indoor relocalisation benchmarks with a defined train/test protocol. 12-Scenes' CC BY-NC-SA 4.0 is also the only relocalisation-grade licence here that explicitly allows public redistribution of derivatives (non-commercially, with attribution). |

### (c) Datasets that need a signed agreement — exact steps found

1. **ScanNet / ScanNet200** — same process for both: fill in the [ScanNet Terms of Use PDF](http://kaldir.vc.cit.tum.de/scannet/ScanNet_TOS.pdf), sign it, email it from your **institutional** address to `scannet@googlegroups.com` [github.com/ScanNet/ScanNet](https://github.com/ScanNet/ScanNet) — accessed 2026-10-04. **No formal SLA** — the README only says "if you have not received a response within a week, it is likely your email is bouncing," implying roughly week-scale turnaround in the typical case, not guaranteed.
2. **Matterport3D** — sign the [MP Terms of Use PDF](http://kaldir.vc.in.tum.de/matterport/MP_TOS.pdf), send from an institutional email to `matterport3d@googlegroups.com`; "We will then provide download access" [github.com/niessner/Matterport](https://github.com/niessner/Matterport) — accessed 2026-10-04. **No SLA stated.** Note the ToU explicitly forbids non-academic use and building a "Showcase-like" online experience from the data — read this closely before any public hosting.
3. **HM3D / HM3D-Semantics** — create a free Matterport account → **Settings → Developer Tools** → under "Habitat-Matterport 3D Research Dataset" click **Request Access** and complete the form [matterport.com/habitat-matterport-3d-research-dataset](https://matterport.com/habitat-matterport-3d-research-dataset) — accessed 2026-10-04; once approved, generate an API token and run `habitat_sim.utils.datasets_download` [habitat-sim DATASETS.md](https://github.com/facebookresearch/habitat-sim/blob/main/DATASETS.md) — accessed 2026-10-04. **No SLA stated.** Downloading HM3D pulls HM3D-Semantics v0.2 by default (same gate, one request covers both).
4. **Structured3D** — fill out the [agreement form](https://forms.gle/LXg4bcjC2aEjrL9o8), which records agreement to the Terms of Use; "after we receive your agreement form, we will provide download access" [github.com/bertjiazheng/Structured3D](https://github.com/bertjiazheng/Structured3D) — accessed 2026-10-04. **No SLA stated.**
5. **ScanNet++ v2** — official site states "Apply for access to download the data now" [scannetpp.mlsg.cit.tum.de/scannetpp](https://scannetpp.mlsg.cit.tum.de/scannetpp/) — accessed 2026-10-04, but the exact request form and turnaround time were **not independently opened in this pass** — visit the site directly to find the live form before relying on a specific timeline.
6. **DL3DV-10K** — governed by a custom [Terms of Use PDF](https://github.com/DL3DV-10K/Dataset/blob/main/DL3DV-10K_term_of_use.pdf); the exact gating step (click-through vs. form) was **not independently confirmed** in this pass.
7. **InteriorGS / SceneSplat-7K** — both are Hugging Face `gated:"auto"`, i.e., **instant automated acceptance** of a custom Terms-of-Use click-through, not a manual-review wait — but the actual ToU text was not read in this pass for either; read [InteriorGS_Terms_of_Use.pdf](https://kloudsim-usa-cos.kujiale.com/InteriorGS/InteriorGS_Terms_of_Use.pdf) before using InteriorGS in anything public-facing.

**Practical advice given the 15 Oct registration deadline and 31 Oct Round-1 due date**: none of the gated datasets have a stated SLA, so start the ScanNet, Matterport3D, HM3D, and ScanNet++ requests **tonight** from an institutional email even if you don't end up needing them for the Round-1 morning package — approval could land anytime between hours and weeks, and Round 2/3 (semantics, POIs, on-site capture rehearsal) will benefit from having ScanNet200/Matterport3D/HM3D-Semantics on hand regardless.

## Licence notes (read before any public demo)

- **"Non-commercial research/evaluation" is the norm, not the exception.** Deep Blending, Mip-NeRF 360 (presumed), Tanks & Temples, ScanNet(200), Matterport3D, HM3D, Structured3D, Replica, 7-/12-Scenes are all explicitly or presumptively non-commercial-only. A Techfest academic competition demo is consistent with "research/evaluation" use in every license that says so explicitly (Deep Blending, Gaussian-Splatting's own license text) — but **none of these clear the data for Juspay to ship as part of a commercial product** without contacting the rights-holder.
- **Two confirmed genuinely-permissive licences**: **Eyeful Tower (MIT)** [LICENSE](https://raw.githubusercontent.com/facebookresearch/EyefulTower/main/LICENSE) — accessed 2026-10-04, and **Hypersim (CC BY-SA 3.0)**, which explicitly states the material may be adapted "for any purpose, even commercially" with attribution + share-alike [creativecommons.org/licenses/by-sa/3.0](https://creativecommons.org/licenses/by-sa/3.0/) — accessed 2026-10-04. **ARKitScenes** is a conditional third: Apple's license grants a broader (and arguably commercial-compatible) license to any licensee whose products/services stayed under 700M MAU in every month before August 2024 [LICENSE](https://raw.githubusercontent.com/apple/ARKitScenes/main/LICENSE) — accessed 2026-10-04 — which should cover a student team and, at present scale, Juspay.
- **Don't trust a mirror's self-declared license tag over the original rights-holder's terms.** Confirmed twice in this pass: `nvs-bench/deepblending` tags `license: mit` with no supporting text, and `GaussianWorld/scene_splat_7k` tags `license: cc-by-sa-4.0` (plus a separate undefined `scene-splat-7k-license` name) while repackaging sources that are individually non-commercial and/or forbid redistribution. Treat both as **inheriting the most restrictive upstream term** until the mirror maintainers can show an explicit relicense/permission from the original authors.
- **Tanks & Temples' license page is internally contradictory** — [tanksandtemples.org/license/](https://www.tanksandtemples.org/license/) — accessed 2026-10-04 opens by citing CC BY 4.0 ("even commercially") but its own "License Grant" clause two paragraphs later restricts use to "non-commercial scientific research" and forbids redistribution without written permission. Until the authors resolve this, follow the stricter clause, and do not rely on the CC BY 4.0 framing for a commercial pitch.
- **Structured3D and Matterport3D both contain explicit anti-hosting clauses** worth re-reading verbatim before any public demo: Structured3D's ToU says you "shall not redistribute the downloaded data, in whole or in part" [Terms PDF](https://drive.google.com/uc?export=download&id=13ZwWpU_557ZQccwOUJ8H5lvXD7MeZFMa) — accessed 2026-10-04; Matterport3D's ToU separately forbids building anything resembling a "Matterport 3D Showcase" from the data — exactly the kind of walkthrough viewer Namma Space is building, so treat Matterport3D-derived reconstructions as demo-only within your own non-commercial evaluation, never as a public deliverable link.
