# R2A tracing research notes

Access date: 2026-10-04 (IST)

## TL;DR

- pyKT (https://github.com/pykt-team/pykt-toolkit; metadata via https://api.github.com/repos/pykt-team/pykt-toolkit, accessed 2026-10-04) is actively maintained code (441★, pushed 2026-09-22), with 30+ DLKT models listed in its README (https://raw.githubusercontent.com/pykt-team/pykt-toolkit/main/README.md, accessed 2026-10-04) through 2025/26-era additions (UKT, HCGKT, RobustKT, MoCKT, DenoiseKT); it does not obviously ship BKT/LR baselines itself.
- Honest benchmarking literature (https://arxiv.org/abs/2112.15072 and https://arxiv.org/abs/2101.08349, accessed 2026-10-04) shows DLKT does **not** reliably beat logistic regression/BKT baselines — safe, citable caution against assuming deep KT wins by default.
- Option-level/distractor-aware tracing is established since 2021 (Option Tracing, https://arxiv.org/abs/2104.09043, accessed 2026-10-04) and extended to polytomous multi-task form in 2022 (DP-MTL, https://arxiv.org/abs/2204.14006, accessed 2026-10-04) — not novel by itself.
- 2026 (EMNLP-accepted and preprint) work increasingly uses LLMs as the observation/evidence function feeding classic psychometric models: CoLearn uses an LLM inside a soft-evidence BKT variant (https://arxiv.org/abs/2609.21154, accessed 2026-10-04); PLCD replaces ID embeddings in cognitive diagnosis with LLM-derived concept/process graphs (https://arxiv.org/abs/2609.12403, accessed 2026-10-04); SLOW separates LLM-based fuzzy cognitive diagnosis from instructional action (https://arxiv.org/abs/2603.28062, accessed 2026-10-04); LT-MKT uses LLM text features for multi-domain KT graphs (https://arxiv.org/abs/2608.24005, accessed 2026-10-04).
- No arXiv abstract hits found for exact-phrase "expected information gain" + "computerized adaptive testing", "Bayesian optimal experimental design" + "adaptive testing", or "expected information gain" + "knowledge tracing" (arXiv API queries, accessed 2026-10-04) — flagged as unconfirmed gap/possible innovation room, not a proven absence of related work.
- LLM-era closed-loop adaptive diagnosis exists: EduLoop-Agent combines neural cognitive diagnosis, bounded-ability adaptive testing, and LLM feedback on ASSISTments (https://arxiv.org/abs/2510.22559, accessed 2026-10-04), so "diagnose → choose item → LLM feedback" is already done at a high level. MC-DINA / bug CDM / Bayesian bug models remain not verified this session (Semantic Scholar rate-limited); explicit gap for follow-up.

- **Benchmark honesty — deep learning vs. logistic regression / BKT baselines:**
  - Sarsa, Leinonen, Hellas, "Empirical Evaluation of Deep Learning Models for Knowledge Tracing: Of Hyperparameters and Metrics on Performance and Replicability," arXiv:2112.15072v4 (JEDM submission). Abstract states: "evidence that DLKT models generally outperform more traditional models, but not necessarily by much and not always" and "even simple baselines with little to no predictive value may outperform DLKT models, especially in terms of accuracy." Baselines tested include logistic regression and BKT against Vanilla-DKT, LSTM-DKT variants, DKVMN variants, SAKT. Source: https://arxiv.org/abs/2112.15072 abstract (accessed 2026-10-04). Maturity: paper-only, code/data stated as published alongside but not independently opened this session — UNVERIFIED repo link.
  - Related: "Do we need to go Deep? Knowledge Tracing with Big Data" (arXiv:2101.08349v1), compares deep vs. traditional (logistic/Markov) models on EdNet at scale, questioning whether deep models outperform traditional ones at current dataset scale. Source: https://arxiv.org/abs/2101.08349 abstract (accessed 2026-10-04). Paper-only.
  - **Takeaway for our design**: the literature itself contains honest, citable warnings that naive DLKT-vs-BKT/logistic comparisons are not a given win for deep learning — useful ammunition if our plan leans on a strong BKT/logistic baseline rather than assuming a deep model is automatically better.

- **Newest 2025–2026 KT, LLM-based KT and cognitive diagnosis:**
  - "CoLearn: An Agentic Tutor that Learns its Learner in a Human–AI Co-Learning Loop," arXiv:2609.21154v1, accepted EMNLP 2026, published 2026-09-17. Uses a **soft-evidence variant of Bayesian Knowledge Tracing where an LLM acts as the continuous observation function** (not binary correct/incorrect), plus adaptive question generation targeting weakest topic/misconceptions. Reported (per abstract, not independently re-derived): blind A/B preference 68–69% for memory-conditioned questions; persona-simulation convergence toward hidden ground-truth mastery. Source: https://arxiv.org/abs/2609.21154 abstract via arXiv API (accessed 2026-10-04). Maturity: paper-only (EMNLP 2026 accepted), code status UNVERIFIED.
  - "Incorporating Cognitive Load and Knowledge Transfer for Multi-Domain Knowledge Tracing" (LT-MKT), arXiv:2608.24005v1 (2026-08-25). Uses LLM-derived text features to build a "Multi-domain Hierarchical Graph" bridging isolated knowledge domains; claims SOTA on real-world multi-domain datasets (specific numbers not opened — UNVERIFIED). Source: https://arxiv.org/abs/2608.24005 abstract (accessed 2026-10-04). Paper-only.
  - "Beyond ID Embeddings: Process-Grounded Language Modeling for Cognitive Diagnosis" (PLCD), arXiv:2609.12403v1, accepted EMNLP 2026 (2026-09-11). Replaces ID-based embeddings in CDMs with LLM-derived "concept schemas and cognitive process graphs," target-conditioned semantic memory, DA-MoE mapper; claims improved cold-start robustness and cognitive-transfer. Source: https://arxiv.org/abs/2609.12403 abstract (accessed 2026-10-04). Paper-only, no code link found in abstract page.
  - "SLOW: Strategic Logical-inference Open Workspace for Cognitive Adaptation in AI Tutoring," arXiv:2603.28062v1 (2026-03-30). Separates learner-state inference (causal evidence parsing from learner language + "fuzzy cognitive diagnosis with counterfactual stability analysis") from instructional action selection in an LLM tutor; evaluated via human-AI hybrid judgments (no numeric deltas opened — UNVERIFIED). Source: https://arxiv.org/abs/2603.28062 abstract (accessed 2026-10-04). Paper-only.
  - General context: "The Path to Conversational AI Tutors..." arXiv:2602.19303v1 (2026-02-22) explicitly argues conversational LLM tutors should "keep" knowledge tracing and affect detection from legacy ITS while using generative AI for dialogic scaffolding — a synthesis/position paper, not a new model. Source: https://arxiv.org/abs/2602.19303 abstract (accessed 2026-10-04).

### 2. Option-level / distractor-aware / misconception-aware tracing

- **Option Tracing: Beyond Correctness Analysis in Knowledge Tracing** — Ghosh, Raspat, Lan, AIED 2021, arXiv:2104.09043v1 (2021-04-19). Extends KT beyond binary correctness to predicting the *exact option* a student selects on MCQs; evaluated on two large-scale student response datasets; qualitatively finds clusters of incorrect options across questions corresponding to the same underlying error (i.e., misconception clusters emerge from option-choice modeling). Source: https://arxiv.org/abs/2104.09043 abstract (accessed 2026-10-04). Maturity: paper-only in this session (no repo independently opened — UNVERIFIED code availability, though pyKT README references related AKT repo by same Ghosh as a separate project).
- **No Task Left Behind: Multi-Task Learning of Knowledge Tracing and Option Tracing for Better Student Assessment (DP-MTL)** — An, Kim, Kim, Park, AAAI 2022, arXiv:2204.14006v1 (2022-04-08). Explicitly frames MCQs as **polytomous** and combines dichotomous KT (correct/incorrect) with polytomous Option Tracing (OT) in one multi-task architecture; KT objective acts as a regularizer for OT; claims significant improvement on both KT and OT, plus benefit to downstream Score Prediction — exact deltas not opened (UNVERIFIED numeric values). Source: https://arxiv.org/abs/2204.14006 abstract (accessed 2026-10-04). Paper-only, no code link found in abstract.
- Targeted arXiv search for `"polytomous" AND "knowledge tracing"` returned only the DP-MTL paper above (1 result) as of 2026-10-04 — suggests the "polytomous KT" framing has not been broadly re-used as a search term beyond this 2022 paper; later misconception-aware work (PLCD, CoLearn, SLOW above) uses different vocabulary (cognitive diagnosis, process graphs, fuzzy diagnosis) rather than "polytomous."
- MC-DINA / bug cognitive diagnosis models (CDM) / Bayesian bug models: **no primary source opened this session** — Semantic Scholar queries for "bug cognitive diagnosis model Bayesian" returned HTTP 429 (rate-limited) on repeated attempts and were not retried further within budget. UNVERIFIED — flagging as a gap; classic references (not opened) would likely include de la Torre's MC-DINA papers and Brown & Burton–style "bug" diagnostic models, but these are not confirmed via primary source in this pass.

## Implications for our design

### Borrow

- A strong **logistic regression / BKT baseline** is legitimately competitive per Sarsa et al. (arXiv:2112.15072) and Do-we-need-to-go-Deep (arXiv:2101.08349) — build and report this baseline honestly rather than assuming deep KT auto-wins; this also de-risks our project if we don't have time to tune a deep model.
- Option Tracing (arXiv:2104.09043) and DP-MTL (arXiv:2204.14006) are the direct precedent for "predict which wrong option, not just wrong/right" — if our misconception tutor models specific distractor choices, cite these as prior art and differentiate (e.g., via LLM-derived misconception labels rather than opaque option-ID embeddings).
- CoLearn's "LLM as continuous observation function for BKT" (arXiv:2609.21154) and PLCD's "LLM-derived concept schemas replacing ID embeddings" (arXiv:2609.12403) are close analogues to any plan that uses an LLM to turn free-text/partial-credit responses into soft evidence for a psychometric model — worth citing as closely related 2026 concurrent work, not something to claim as entirely novel.

### Innovation room

- No arXiv abstract hits for exact "expected information gain" + "computerized adaptive testing" or "Bayesian optimal experimental design" + "adaptive testing" phrasing (both 0 results, accessed 2026-10-04) — if our design explicitly frames next-question selection as EIG/BOED over a misconception-aware latent state, that specific framing combination may be underexplored term-wise (though substance may exist under other vocabulary — not conclusively a gap, just unconfirmed by phrase search).
- Combining option-level/distractor tracing (2021-era) with 2026-era LLM-as-observation-function (CoLearn) and LLM-as-cognitive-prior (PLCD) plus explicit EIG over executable misconception programs does not appear to have a single unified paper yet in what was searched — potential white space. Caveat: EduLoop-Agent already covers the broader closed-loop NCD + adaptive testing + LLM feedback pattern.

### Already done — do not claim novel

- Option-level/distractor-level KT: done since 2021 (Ghosh/Raspat/Lan) and extended 2022 (DP-MTL polytomous multi-task). Do not present "predicting the wrong answer, not just wrong/right" as a novel contribution by itself.
- "LLM tracks mastery/misconceptions and personalizes next question" as a general pattern: done in CoLearn (2026-09), SLOW (2026-03), LT-MKT (2026-08), PLCD (2026-09), and EduLoop-Agent (2025-10) — all recent/concurrent work. Differentiate on specifics (e.g., executable misconception bug programs, multi-misconception Bayesian tracer, specific EIG item-selection math, or domain) rather than the high-level pattern.
- "Deep learning doesn't always beat simple baselines in KT" is an established, citable finding (2021/2022 papers) — safe to assert with citation, not a novel finding to claim ourselves.
